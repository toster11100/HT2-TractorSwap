# Локальная проверка 1.1.1

Полностью закрыть игру и запустить её через Steam. Локальная папка `Dev` подключена в `workshop.cfg` как `TractorSwapDev` с приоритетом -1000: это позволяет проверять 1.1 поверх опубликованной версии 1.0 без её обновления в мастерской.

На момент подготовки игра была открыта и Windows не разрешила заменить загруженный `plugins/HT2_TractorSwap.asi`. Готовый новый файл находится в `Dev/plugins/HT2_TractorSwap.asi`; его установит штатный синхронизатор при следующем запуске через Steam.

После перезапуска в `HT2_TractorSwap_Status.ini` должны появиться `Version=1.1.1`, `Result=Installed` и один из профилей: `SteamOriginal` или `ModifiedCore82`. Сам номер 1.1.1 использовался и в предварительном тесте, поэтому для точной проверки файла следует сравнивать SHA256:

`d24d5fee65c57e948dc2f4bded69d6e42df402ec7b368e21ecf264998bd53a9b`

## Что проверять

1. F4 → «Моя компания». Кнопка «Поменяться местами» доступна при любом выбранном водителе.
2. Сам выбор водителя не отправляет сообщения.
3. Нажатие на обмен с обычным наёмником на тягаче выполняет штатный обмен.
4. Нажатие на обмен с участником гонки оставляет машины и статус гонки прежними, а причину отправляет в пейджер и закрывает окно компании штатным способом. Русский текст выбирается по `ENV/langv=rus` в TRUCK.INI.
5. Если игрок сам участвует в гонке, сообщение указывает это; если оба водителя — указывает обоих.
6. При отсутствии выбранного водителя нажатие предлагает выбрать наёмника.
7. Кнопка увольнения работает по прежним правилам.

Пейджер обрабатывает сообщения штатным способом. В меню F4 игровой мир и пейджер могут быть приостановлены: при отказе из-за гонки окно компании закрывается автоматически, чтобы сообщение стало видно. Для прочих отказов окно остаётся открытым. Очередь и подавление одинаковых повторов остаются штатными; заполненная очередь не перезаписывается модом.

## Проверки разработчика

3388 проверок x86 в Unicorn прошли для обоих профилей: установка и отказ на изменённых сигнатурах, активная кнопка, проверка гонки именно при нажатии, отсутствие уведомлений при выборе, сохранение регистров и стека, переход других кнопок в исходный обработчик, штатная очередь пейджера без перезаписи, смена базы ASI и неизменённый блок обмена машин/прицепов. Windows LoadLibrary/FreeLibrary также прошли.

Предварительная версия 1.1 была проверена в самой игре на оригинальном Steam EXE: выполнен обмен с Ириной на Peterbilt 379, блокировка Натальи сохранена и сообщение появилось в пейджере. После этого логика изменена по просьбе пользователя: кнопка всегда активна, уведомление только по нажатию; выбор языка исправлен. Последнюю сборку пользователь проверяет самостоятельно.

Работа с прицепами и сохранениями не менялась. На момент подготовки в корне находился оригинальный Steam EXE. Резервная копия Modified Core находится в `backup/before_1.1/king_core.exe`.

Для прекращения локального теста убрать строку `setf ~local_mod_folder TractorSwapDev ...` из `workshop.cfg` при закрытой игре и запустить игру через Steam. В мастерской остаётся версия 1.0.0.

## Изменение 1.1.1

По просьбе пользователя отказ из-за участия игрока, наёмника или обоих в гонке теперь закрывает меню после отправки сообщения. Вызывается исходный хвост закрытия окна без блока обмена, смены машины или гоночных флагов. Подпись и доступность кнопки прежние. Остальные отказы сохраняют открытое окно.

Закрытие, возврат управления, стек и сохранённые регистры проверены выполнением исходного x86-кода для обоих EXE. Русские и английские причины проверены целиком, английский текст содержит только ASCII и укладывается в 128-байтовый буфер пейджера. Полноценная проверка отображения в английской игре не выполнялась.

## Локализации перед релизом 1.1.1

Добавлены французский (fra), немецкий (ger) и испанский (spa), подтверждённые таблицей языков EXE. Поддержаны также fre/deu/esp и верхний регистр; неизвестный код использует английский текст. Все пять причин для каждого языка выполнены в Unicorn для обоих EXE, включая закрытие окна только для гонщиков и штатную очередь пейджера. Латинские тексты используют только ASCII, укладываются в буфер и не требуют проверки диакритики шрифтов. Полная проверка отображения новых языков в игре не выполнялась. Полный текст фраз сохранён в MESSAGES.json.

Запасная причина теперь сформулирована точно: «Обмен недоступен: не удалось определить водителя». Она применяется при некорректной ссылке на игрока/выбранного водителя; это не дополнительное правило игрового обмена.
