# HT2 Tractor Swap 1.1.4

Tractor Swap разрешает использовать действие обмена машинами в меню компании с наёмными водителями, у которых трактор. Передача машины выполняется штатной функцией игры; остальные штатные условия обмена сохраняются.

## Возможности

- Доступен обмен тягач ↔ тягач, тягач ↔ обычный грузовик и тягач ↔ легковушка.
- Действие доступно в меню компании; запрет из-за гонки проверяется при нажатии.
- Если в гонке участвует игрок, выбранный водитель или оба, обмен отменяется, окно компании закрывается, а пейджер объясняет причину. Машины и гоночный статус отказом не изменяются.
- При доступном Steam API язык пейджера определяется по настройкам Steam: русский, английский, французский, немецкий или испанский.

## Поддерживаемые профили EXE

Совместимость проверяется по метаданным EXE и сигнатурам кода; одного номера версии недостаточно.

| Профиль | Эталонный SHA-256 | Примечание |
| --- | --- | --- |
| `KOTR81` | `31fbd1dbbe7706183f09a3688482791255db2bfb557c02675374b96796ce2ebd` | Эталон русской версии King of the Road 8.1 |
| `KOTR13` | `0df6861c9e67c2a2ae373cff8d765ae41cc76079d8f84b9340e609263edd983f` | Проверенный эталон международной King of the Road 1.3 |
| `ModifiedCore82` | `b57eb1e34dd00c6c5270ca42ada931039d9baed488dee5bb33f46ffa2a6097d6` | Modified Game Core 8.2 |

Сборка GOG отдельно не проверялась и не считается совместимой только на основании номера 1.3. EXE должен соответствовать проверенному профилю и пройти встроенные проверки сигнатур; для заявления поддержки также нужен отдельный runtime-тест. В опубликованном ASI 1.1.4 сохранены старые диагностические метки `SteamOriginal` / `SteamFrench`, чтобы воспроизводить тот же бинарник; в текущей документации используются нейтральные имена профилей.

## Установка и удаление

Требуются Windows, поддерживаемый 32-битный EXE игры и совместимый ASI Loader. Закройте игру и сделайте резервную копию профиля `.pl1`. Скопируйте `plugins/HT2_TractorSwap.asi` из ZIP в папку `plugins` игры, затем запустите игру.

Откройте **F4 → Моя компания**, выберите наёмного водителя и используйте действие обмена. Для удаления закройте игру и удалите `plugins/HT2_TractorSwap.asi`. Мод не меняет EXE игры на диске и не вводит собственный формат сохранений; обмен машин сохраняется по обычным правилам игры. Удаление ASI не удаляет файлы сохранений.

Файл `HT2_TractorSwap_Status.ini` создаётся рядом с EXE игры. `Result=Installed` означает, что изменения применены в памяти. `UnsupportedExecutableOrConflict` — EXE или ожидаемый код не совпали; `VirtualProtectFailed` — Windows не разрешила изменение памяти; `InstalledProtectionRestoreFailed` — патч применён, но защиту страницы восстановить не удалось.

## Зависимости во время игры, совместимость и ограничения

Нужны игра и ASI Loader. При наличии Steam API мод использует его для определения языка пейджера; зависимости от AutoSave или других модов во время запуска нет. Совместимость с HT2 AI Trailers 1.3.3, D2GI и Modern Patch проверялась, но эти компоненты не требуются.

Известное ограничение прицепов: с HT2 AI Trailers 1.3.3 прицеп наёмного водителя может стать невидимым, пока игрок управляет его тягачом. В предыдущих заметках указано, что прицеп снова появляется после обратного обмена; Tractor Swap не преобразует и не исправляет представление ИИ-прицепа. Это поведение не связано с изменением сохранения.

## Сборка и тесты

Нужны Python 3.10+ и Windows. Зависимости ассемблера/сборки PE и тестов закреплены в `requirements.txt` и `requirements-test.txt`:

```powershell
python -m pip install -r requirements-test.txt
$env:HT2_BUILD_INPUTS = 'C:\путь\вне\репозитория\к\локальным\файлам\игры'
python build.py
python -m tests.test_mod
python -m tests.test_steam_language
python package_release.py
```

`HT2_BUILD_INPUTS` должен указывать на каталог вне репозитория со следующими файлами:

| Файл | Ожидаемый SHA-256 |
| --- | --- |
| `KOTR81.exe` | `31fbd1dbbe7706183f09a3688482791255db2bfb557c02675374b96796ce2ebd` |
| `KOTR13.exe` | `0df6861c9e67c2a2ae373cff8d765ae41cc76079d8f84b9340e609263edd983f` |
| `ModifiedCore82.exe` | `b57eb1e34dd00c6c5270ca42ada931039d9baed488dee5bb33f46ffa2a6097d6` |

Игровые эталоны не включены. `build.py` пишет ASI и сгенерированный ассемблер только в игнорируемый `build-output/`; зафиксированный `build.asm` — проверенный исходник ассемблера. Упаковщик принимает только ASI версии 1.1.4 с известным SHA-256 и создаёт минимальный ZIP без обложек и игровых файлов.

В [истории изменений](docs/CHANGELOG.md) записаны изменения 1.1.4. Тексты сообщений игры хранятся в `build.py`.
